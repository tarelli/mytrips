# mytrips

An animated map of every flight I have taken between 2009 and 2026, reconstructed
from booking confirmations in my inbox.

**Live map → https://tarelli.github.io/mytrips/**

275 flight legs · 66 cities · 20 countries · 5 continents · 21 years

The house marker shows where I was living at any given moment: Paris, Cagliari,
Milan, Cork, Cagliari, Oxford, Vicenza, Cagliari. The counters track years elapsed
and cumulative days spent away from home base.

Single self-contained HTML file. Leaflet + CartoDB basemap, no build step,
no dependencies to install.
